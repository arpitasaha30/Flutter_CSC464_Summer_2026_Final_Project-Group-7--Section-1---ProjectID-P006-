# Chat App (Flutter + Firestore)

A 1-to-1 real-time chat app matching the P006 project spec: user registration,
a users list, a chats list, real-time messaging, and a deterministic unique
chat room per pair of users — using **Firestore only** (no Firebase Auth).

This zip contains only the Dart source (`lib/`) and `pubspec.yaml` — the
platform folders (`android/`, `ios/`) are generated by the Flutter CLI in
step 1 below, and Firebase config is generated in step 2. This is the normal
way to receive Flutter source: platform folders are machine-generated and
must be created on your own machine so they match your installed Flutter/SDK
versions.

## 1. Create the project shell

In VS Code, open a terminal in an empty folder and run:

```bash
flutter create chat_app
```

Then **copy everything from this zip into that folder**, overwriting the
generated `lib/` folder and `pubspec.yaml`. This gives you a real
`android/` and `ios/` folder built for your machine, plus our app code.

```bash
cd chat_app
flutter pub get
```

## 2. Create a Firebase project

1. Go to https://console.firebase.google.com and create a new project.
2. In the project, go to **Build → Firestore Database → Create database**
   (start in test mode for development).
3. Install the FlutterFire CLI (one-time):
   ```bash
   dart pub global activate flutterfire_cli
   ```
4. From your `chat_app` folder, run:
   ```bash
   flutterfire configure
   ```
   Select your Firebase project and the platforms you want (Android/iOS).
   This automatically adds `android/app/google-services.json`,
   `ios/Runner/GoogleService-Info.plist`, and wires up the Gradle/CocoaPods
   plugins for you — no manual editing needed.

   If you'd rather do it without the CLI: download `google-services.json`
   from **Project settings → Your apps → Android app** and place it at
   `android/app/google-services.json`, then add the Google services Gradle
   plugin as prompted in the Firebase console's setup instructions.

## 3. Firestore security rules

For development, apply the rules in `firestore.rules` (included in this
zip) via **Firestore → Rules** in the console. They're intentionally open
since this project has no Firebase Auth — tighten them before shipping
anything real.

## 4. Run it

Connect your phone (with USB debugging enabled) or start an emulator, then:

```bash
flutter run
```

## What's implemented

- **Registration/Login** — stored in `/users` in Firestore; passwords are
  SHA-256 hashed (`lib/utils/password_utils.dart`) and never stored in plain
  text, per the spec.
- **Session persistence** — `shared_preferences` keeps you logged in
  between app launches.
- **Users tab** — live list of all other registered users, searchable.
- **Chats tab** — live list of your conversations with last message + time.
- **Chat screen** — real-time messages via Firestore snapshots, sent/received
  bubble styling, timestamps.
- **Unique chat rooms** — `lib/utils/chat_room_utils.dart` sorts the two user
  IDs so `A_B` and `B_A` always resolve to the same room ID, and
  `ChatProvider.getOrCreateChatRoom` checks-then-creates to avoid duplicates.
- **State management** — `AuthProvider`, `UserProvider`, `ChatProvider`,
  `MessageProvider`, exactly as specified, wired up via `provider` in
  `main.dart`.

## Troubleshooting

- **"No Firebase App has been created"** — you skipped step 2; run
  `flutterfire configure` (or add `google-services.json` manually).
- **Users/chats not showing up** — check Firestore rules are published, and
  that you're online.
- **Build fails on Android** — make sure `android/build.gradle` /
  `android/app/build.gradle` still have the Google services plugin lines
  that `flutterfire configure` or the Firebase console instructions added.
